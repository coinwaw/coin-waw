# Contributing to Coin Waw

Coin Waw welcomes contributors interested in:

- crypto
- finance
- economics
- journalism
- data
- programming
- research
- design

## Ways to Contribute

### News
Submit relevant market-moving news with an original source.

### Research
Contribute market research, data analysis, or educational material.

### Development
Help improve the news bot, data pipeline, website, APIs, and automation.

### Community
Help moderate discussions and improve the community experience.

## News Submission Format

```text
Title:
Source:
URL:
Published:
Category:
Assets:
Summary:
```

## Pull Requests

Before submitting:

1. Explain what changed.
2. Explain why it is useful.
3. Keep changes focused.
4. Never include secrets or private credentials.
5. Provide sources for factual financial claims.

## No Financial Manipulation

Contributors must not intentionally:

- fabricate news
- create fake partnerships
- impersonate organizations
- manipulate market information
- publish stolen credentials
- publish private information

## Code of Conduct

Be respectful.

Debate ideas, not people.

Coin Waw aims to build an open and constructive community.
