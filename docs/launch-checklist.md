# Coin Waw Launch Checklist

Use this checklist before publicly promoting $WAW.

## Identity

- [ ] Official X account: https://x.com/coinwaw
- [ ] GitHub repository is public
- [ ] Branding is consistent
- [ ] Official links are verified

## Repository

- [ ] README is accurate
- [ ] Roadmap reflects the actual plan
- [ ] Tokenomics contains only verified information
- [ ] No private keys or API credentials are committed
- [ ] News-bot README is accurate

## Token

- [ ] Contract address is verified before publication
- [ ] Network is correctly stated
- [ ] Supply information is verified
- [ ] Wallet disclosures are accurate
- [ ] Liquidity statements are factual

## Communication

- [ ] No guaranteed-return claims
- [ ] No fake partnerships
- [ ] No fake volume or fake community metrics
- [ ] No fabricated news
- [ ] Clear risk disclaimer
- [ ] Avoid misleading price predictions

## After Launch

- [ ] Continue publishing useful news
- [ ] Keep project documentation updated
- [ ] Report material changes transparently
- [ ] Build the news product regardless of short-term token price
