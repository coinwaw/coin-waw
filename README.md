# Coin Waw

> Crypto. Stocks. Finance. One community following the news that moves markets.

**Coin Waw ($WAW)** is a community-driven financial news project focused on crypto, stocks, macroeconomics, and global markets.

**X:** https://x.com/coinwaw

The project aims to make fast-moving financial information easier to discover, understand, and discuss.

## What is Coin Waw?

Financial markets move quickly. A single headline can affect crypto, equities, commodities, currencies, and risk assets.

Coin Waw focuses on:

- 🪙 Crypto
- 📈 Stocks
- 🏦 Macro & economics
- 💵 Finance
- 🌎 Global markets
- 📰 Breaking news
- 🔎 Market research

### Core principle

**Information before hype.**

We want Coin Waw to remain useful even when market hype disappears.

## News Bot

The repository includes a small starter RSS news collector.

It can:

- read RSS feeds
- collect article metadata
- remove duplicate URLs
- classify articles using simple keyword rules
- save structured JSON to `data/news.json`
- preserve source URLs and timestamps

The bot is intentionally simple so it can be extended later.

See [`news-bot/README.md`](news-bot/README.md).
